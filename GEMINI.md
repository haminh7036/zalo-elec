# Zalo-elec Project Instructions

## Project Overview
`zalo-elec` is an unofficial, native-like Electron wrapper for Zalo Web (`https://chat.zalo.me`). It provides a desktop application experience by utilizing Electron, written in TypeScript. 

Key features include:
- **User-Agent Spoofing:** Masks the application as a standard Chrome browser to bypass Zalo's Electron detection, enabling full features like QR code login.
- **System Integration:** Includes a system tray icon, persistent single-instance locking, OS notifications, and proper media permissions (microphone, camera).
- **ZaDark Emoji Injector:** Injects custom ZaDark emoji styles and scripts directly into the Zalo web DOM upon load.
- **Link Handling:** Forces all external links to open in the user's default system browser rather than inside the app wrapper.

## Architecture
- **Language/Framework:** TypeScript, Node.js, Electron.
- **Packaging:** `electron-builder` is used to package the app for distribution (e.g., AppImage and deb for Linux).
- **Directory Structure:**
  - `src/main/`: Contains the main process TypeScript source code (`index.ts`, `tray.ts`).
  - `dist/`: The compiled JavaScript output generated by `tsc`.
  - `resources/`: Contains static assets like the app icon and the emoji injector scripts/CSS.

## Building and Running
The project relies on standard pnpm scripts defined in `package.json`:

- **Build:** Compile TypeScript to JavaScript.
  ```bash
  pnpm run build
  ```
- **Start (Development):** Compile and launch the Electron application locally.
  ```bash
  pnpm run start
  ```
- **Package:** Compile and package the application for distribution using `electron-builder`.
  ```bash
  pnpm run dist
  ```

## Development Conventions
- **TypeScript:** All new source code should be written in TypeScript within the `src/` directory.
- **Electron APIs:** The app relies on main process APIs (like `BrowserWindow`, `session`, `app`, `Tray`, `Menu`) to orchestrate the web wrapper. Ensure context isolation is maintained and the web wrapper remains sandboxed.
- **Web Wrapper Focus:** Since this is a web wrapper, avoid adding heavy native Node.js dependencies unless necessary for the main process.
- **Styling/Injects:** Custom DOM manipulations (like the ZaDark emoji feature) are handled via `webContents.insertCSS` and `webContents.executeJavaScript` after the DOM is ready. Any future web injections should follow this pattern.
